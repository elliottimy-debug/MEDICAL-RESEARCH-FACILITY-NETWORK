IT Department Staff Structure

The proposed IT department structure separates management, network administration, systems support, security and user support to keep reporting lines clear.

Position Main Responsibilities & Contact Info Reports To
IT Manager Monitors performance, provides strategic direction, budget approval, IT policy enforcement, and final approval for hardware acquisition and disaster recovery procedures.
Email: it.manager@medresearch.org 		Facility Director
Network & Systems Administrator Responsible for managing the organization's network infrastructure, central server, and cloud infrastructure, and overall network security and backup procedures.
Email: net.sys.admin@medresearch.org 		IT Manager
Help Desk First-line support to users and escalated tickets for administrative staff and lab technicians while meeting SLAs.
Email: servicedesk@medresearch.org 		IT Manager
IT Support Technicians Hardware and software troubleshooting, providing technical support to administrators in the main block, computer terminals in the lab floors, and enforce security policies.
Email: support.tech@medresearch.org 		Help Desk
IT Security Officer Security policies, access controls, security monitoring, incident reporting and awareness.
Email: security.officer@medresearch.org 		IT Manager
