Disaster Recovery Plans

Disaster recovery is concerned with restoring IT services after a serious disruption. A useful recovery plan should identify important systems, recovery priorities, responsible staff, backup arrangements and the steps required to restore services.

Disaster Recovery Scenarios and Action Plans

Disaster Scenario Impacted Infrastructure Recommended Action & Recovery Plan
Primary Uplink / Network Cable Failure Core-to-Building connectivity RSTP Auto-Failover: Rapid Spanning Tree Protocol (RSTP) automatically unblocks secondary redundant links between building switches and the Core Switch within <2 seconds.
Core Layer 3 Switch Hardware Failure Facility-wide inter-VLAN routing and central DHCP Redundant Core Deployment: Implement High Availability using Hot Standby Router Protocol (HSRP) / Virtual Router Redundancy Protocol (VRRP) with a redundant secondary Core Switch.
Research Management Server Outage Central Research Management Software (192.168.10.10) Server Failover & Backups: Daily off-site automated backups and hot-standby virtual machine replication to allow instant failover.
Facility Power Outage/Failure Core Server Room & Floor Switches UPS & Generator Backup: Server room and switch racks equipped with Uninterruptible Power Supply UPS units providing 30 minutes runtime, backed by an automated diesel generator.
Physical Cyber Attack or ASA Firewall Breach ISP WAN / External VPN access Automated ASA Failover & Isolated Subnets: ASA Firewall isolates internal subnets (192.168.10.0–40.0/24) automatically, terminating compromised VPN sessions.
