# Medical Research Facility - Network Infrastructure & IT SOP Portal

## Project Overview
This repository contains the complete documentation, network design files, and internal static intranet website developed for the **Medical Research Facility** project (Module: **XITM5229 - Work-Integrated Learning**).

The project is divided into two primary phases:
1. **Task 1:** Network Infrastructure Planning, Design, Subnetting, and Hardware Specifications.
2. **Task 2:** IT Governance, Standard Operating Procedures (SOPs), Disaster Recovery Plans (DRP), and the internal Static Intranet Website.
